# Security Policy

## Supported versions

Security fixes are released for the latest version of GioCookies available in the
[Releases](https://github.com/GiovanniBevacqua/giocookies/releases) (and on WordPress.org once published). Please update before reporting.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public issues, discussions or pull requests.**

Report them privately through GitHub:
[**Report a vulnerability**](https://github.com/GiovanniBevacqua/giocookies/security/advisories/new)

Please include:

- the affected version;
- a description of the issue and its impact;
- steps to reproduce or a proof of concept.

You will receive an acknowledgement within a few business days. Once the issue is confirmed,
a fix will be released as soon as possible and you will be credited in the changelog, unless you prefer to remain anonymous.

You can also report vulnerabilities in WordPress plugins through the
[Patchstack](https://patchstack.com/database/report) or [Wordfence](https://www.wordfence.com/threat-intel/vulnerabilities/submit) programs.
